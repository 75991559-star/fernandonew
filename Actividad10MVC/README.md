# Actividad de Aprendizaje N.º 10 - MVC

Proyecto en C# con ASP.NET Core MVC, preparado para editarse en Visual Studio Code. Incluye el caso desarrollado de empleados y los casos propuestos de productos y clientes.

## Abrir y ejecutar

1. Abre en Visual Studio Code la carpeta `Actividad10MVC`.
2. Verifica que tengas instalado el SDK de .NET 10 y la extensión **C# Dev Kit**.
3. En la terminal integrada, ejecuta:

   ```powershell
   dotnet run
   ```

4. Abre la dirección local que muestre la terminal.

Los datos se guardan en colecciones `List<T>` en memoria. Se reinician al detener y volver a iniciar la aplicación; esta actividad practica la colección genérica, no una base de datos.
